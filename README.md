# Student Management System

A simple console-based **Student Management System** developed in Java to manage student records efficiently. The project demonstrates core Java programming concepts including **Object-Oriented Programming (OOP), ArrayList, classes, objects, methods, loops, and user input handling**.

## Features

- Add a new student
- View all student records
- Search for a student using Student ID
- Delete a student using Student ID
- Menu-driven console interface
- Basic input handling and validation

## Technologies Used

- **Java**
- **Java Collections Framework**
- **Object-Oriented Programming (OOP)**
- **ArrayList**
- **Scanner**
